# 할 일 관리 앱 PRD

## 1. Why - 목적
- 1년 목표와 일일 실행 단위를 계층적으로 연결
- 일일 할 일 완료 결과를 주간 진행률에 자동 반영해 목표 대비 진척도 가시화

## 2. Who - 타깃 사용자
- 1년 목표를 세우고 주간/일일 단위로 나눠 실행하려는 개인 사용자
- 칸반 방식의 상태 전환과 목표 대비 진척도 확인을 원하는 사용자

## 3. User Flow

**최초 사용**
1. 1년 목표 생성
2. 1년 목표에 연결된 이번 주 계획 작성
3. 주간 계획에 연결된 할 일 생성

**일상 사용**
1. 대시보드에서 이번 주 계획 및 진행률 확인
2. 할 일 생성 / 수정 / 삭제
3. 드래그 앤 드롭으로 상태 변경
4. 상태 변경 시 주간 진행률 자동 갱신

## 4. 기능 요구 사항

### P0 - 핵심 기능

**할 일 관리**
- 할 일 생성 / 수정 / 삭제
- 필드: 제목(필수), 설명, 날짜, 연결 주간 계획
- 상태: `todo` / `doing` / `done` (생성 시 기본값 `todo`)

**드래그 앤 드롭**
- 칸반 보드: todo / doing / done 3개 컬럼
- 모든 컬럼 간 양방향 이동 가능
- 이동 즉시 저장, 실패 시 원래 컬럼 복귀 + 오류 표시

**주간 계획**
- 주간 계획 생성 / 수정 / 삭제 (주당 최대 5개)
- 요일별 할 일 배치

**1년 목표**
- 1년 목표 생성 / 수정 / 삭제
- 목표별 설명 작성

**연결 구조**
- 할 일 → 주간 계획: N:1
- 주간 계획 → 1년 목표: N:1
- 상위 항목 삭제 시 하위 항목은 연결 해제 (삭제하지 않음)
- 미연결 할 일 허용

**주간 진행률 자동 반영**
- 계산식: `done 할 일 수 / 연결된 전체 할 일 수 × 100`
- 갱신 시점: 할 일 생성 / 삭제 / 상태 변경 / 연결 변경
- 할 일 0개일 경우 0% 표시

**대시보드**
- 이번 주 계획 목록
- 주간 계획별 진행률 표시

### P1 - 추가 기능
- 우선순위 설정 (High / Medium / Low)
- 마감일 설정
- 1년 목표 진행률 표시 (연결된 주간 계획 진행률 평균)
- 주간 메모 작성
- 주간 회고 작성
